# Polishing Scope — Валидация

Дашборд для валидации задач из ClickUp (Project = "Polishing scope", Yerevan Mall Audit 2026).

Задачи разбиты на три группы:

- **Ручная проверка** — можно проверить визуально, без технических навыков
- **Проверка через аналитику** — Firebase Crashlytics/Performance, GA4, Pushwoosh
- **Требует технического доступа** — только через бэкенд/базу данных

Каждой задаче можно проставить статус: *ожидает проверки* / *отвалидировано* / *провалено*.

> Статусы сейчас хранятся локально (в `localStorage` браузера) — синхронизация между людьми пока не подключена.

## Разработка

```bash
npm install
npm run dev
```

## Деплой

Пуш в `main` автоматически собирает и публикует сайт на GitHub Pages через Actions.
